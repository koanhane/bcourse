# bCourse Remind Me case study

Upload this folder’s contents together to your GitHub Pages publishing folder. index.html belongs at the root, beside presentation.css, editorial.css, site.js, .nojekyll and assets/. All references are relative. Preserve names and capitalization.

The case study has nine sections in a natural scrolling page. The middle chapters use screen-sized story panels; the original Introduction and closing sections retain editorial layouts. Use the left contents to jump between sections. Supplied screens can be opened at full resolution.

assets/project-walkthrough.mp4 is a 55-second guided walkthrough at 780 × 1688, played automatically at 2× (about 28 seconds per loop). It combines supplied new-page screenshots with the recorded Lab 6 reminder interaction; it is not a new full interaction recording. The on-page explanation follows its current stage.

assets/latest-prototype.html opens the interactive prototype. Keep assets/prototype-pages/ together with it so page links work.

Desktop layout checked at 1280 × 720. Story panels are sized for a screen; scroll between them. Small-screen layouts adapt; a landscape or desktop viewport is recommended for presenting the multi-screen comparisons.
